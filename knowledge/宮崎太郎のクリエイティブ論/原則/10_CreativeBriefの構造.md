# 原則10：Creative Briefの構造

## 命題

**Creative Briefは「相互関係」で機能する。断片的に知っていても意味がない。**

> 断片的には聞いたことがあるだろうけど、本当は相互関係を整理して初めて役に立つもの。
> とても大事な基礎概念なのに、ドメの代理店では誰も教えてくれないこと。

## フィールドと相互関係

### 左側（ブランド・ビジネス軸）
| フィールド | 定義 |
|---|---|
| Brand Name | ブランドの名前 |
| Brand Philosophy / Brand Purpose | ブランドの哲学・社会的役割 |
| Brand Slogan | ブランドの宣誓 |
| Brand Promise | ブランドが生活者に約束すること |
| Business Goal | ビジネスとして目指すゴールイメージ |
| Ad Role | ビジネスゴールを叶えるために広告が果たす役割 |
| Problem | 商品の抱える課題 |
| Competitor | 競合商品 |
| USP | 唯一無二の提案・競合優位点（FACTをBENEFITに翻訳した消費者への約束） |
| Fact | USPを裏付ける事実 |

### 右側（生活者・クリエイティブ軸）
| フィールド | 定義 |
|---|---|
| Target | ターゲット |
| Target Insight | ターゲットの潜在的欲求（必ず「実は〜」の形で） |
| Social Insight | 社会環境・社会的な潜在的欲求・課題 |
| Before Perception | 現状のブランドへの認識 |
| After Perception | 作りたい新たな認識 |
| Tone & Manner | 守るべきブランドのトーン（地雷） |
| Campaign Concept | キャンペーンのテーマ |
| Campaign Tagline | キャンペーンをまとめるコピー |
| Key Visual | 象徴となるアイコン |
| Catch Copy | アテンションを獲得するための投げかけ |

## 重要な相互関係

- **USP = FACT × BENEFIT**：FACTがあってもBENEFITに翻訳しないとUSPではない
- **Before/After Perception**：広告の仕事は「状態変化の設計」。この2行が書けないブリーフは手段が目的化している
- **Target Insight**：「〜と思っている」ならパーセプション。「実は〜」と書けるときだけインサイト
- **Ad Role**：Business GoalとTarget Insightをつなぐ橋。ここが曖昧だと施策が散る
- **Campaign Concept → Tagline → Catch Copy**：この3行は階層構造。ConceptがあってはじめてTaglineが立ち、TaglineがあってはじめてCatch Copyが生きる

## 応用

ブリーフを受け取ったとき、まずこの20フィールドを埋めようとすることで「情報の欠落」が見える。
埋められないフィールドが、そのままクライアントへの質問リストになる。
