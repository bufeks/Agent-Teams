# kiCk inc. 社内グレード設計

## グレード体系（全職種共通）

| Grade | サブグレード | 役位 | 影響範囲 | 時間軸 | 役割定義 |
|-------|------------|------|---------|--------|---------|
| G5 | - | 取締役 | 全社/業界 | 5-10年 | kiCkがどんな未来に賭ける会社であるかを決め、その結果を引き受ける人 |
| G4 | Manager | 執行役員・部長 | 部門 | 3-5年 | 部門の未来を引き受け、変化を"続く形"にする人 |
| G3 | Manager | 課長 | チーム | 1-3年 | チームの成果と成長を同時に引き受ける人 |
| G2 | Chief | 主任 | 自分＋後輩 | 1年 | 自分の仕事を自分で設計し、周囲に良い影響を広げる人 |

## 全グレード共通：期待される在り方・行動

### G5（取締役）
- 社会・業界・会社に染みついた「当たり前」を疑い、まだ名前のない可能性を企てる
- ワクワクする未来像を、構想で終わらせず 意思決定・資源配分・行動として背負う
- 成功しているやり方にも"意図的なバグ"を仕込み、変化が起こる余白を設計する
- 事業・組織・文化のどこに挑戦の余白を残すかを決め、進化の方向を定義する
- 外部の力と共謀し、kiCkの立ち位置（何者か）を更新し続ける
- 自分が抜けた後も残る 思想・判断基準・問いの置き方 を次世代に手渡す

### G4（執行役員・部長）
- 部門の中長期の目的を描き、ワクワクを"方針と打ち手"に翻訳する
- 部門の慣習や既成概念に違和感を持ち、別のやり方を現実として成立させる
- 成果・人・関係性の最終判断から逃げず、「自分が引き受ける」で前に進める
- 部門を越えた連携や外部協働を通じて、価値の出口を増やし続ける
- 一回の成功で終わらせず、次も挑戦できる状態を仕組みと人に残す
- kiCkらしい「判断のクセ」を、部門の言葉と行動で示す

### G3（課長）
- チームが「何のために存在するか」を言葉にし、迷ったときに戻れる軸をつくる
- 目の前の課題を作業で終わらせず、意味のある挑戦としてチームに返す
- メンバーの違いを武器にし、組み合わせて成果を出す
- 炎上の兆し・停滞の違和感を早く掴み、小さいうちに手を打つ
- 新しいやり方を現場で試し、チームの選択肢を増やす
- 情熱で場を温め、考えて動く文化を当たり前にする

### G2（主任）
- 与えられた役割を鵜呑みにせず、目的から自分の動きを組み立てる
- 業務の違和感・ムダ・ズレを放置せず、小さく試して前に進める
- 上司や先輩の意図を汲み取りつつ、自分の問いと考えを持つ
- 後輩に向き合い、やり方だけでなく"判断のしかた"を共有する
- 失敗をなかったことにせず、学びとして次に接続する
- 「もっと良くできる余白」を探すことを、自分からやめない

### G1（メンバー）
- 指示や依頼の背景を理解しようとし、仕事の意味を掴みにいく
- わからないことを放置せず、質問と学習で前に進める
- 任された仕事を最後までやり切り、信頼を積み上げる
- フィードバックを前向きに受け止め、行動を変える
- 新しいやり方や考え方に触れることを恐れず、変化に身を置く
- 自分の成長が、チームや会社のワクワクにつながると理解する

## 昇格要件（原則）

**★ 現等級の「期待される在り方・行動」を再現性をもって体現している**
**★ 一時的ではなく、一定期間続いている**
**★ 周囲（上司・同僚・後輩・関係者）から見て「すでに次の等級の動きをしている」と認識されている**
**★ 役割や肩書きではなく、引き受けている責任の重さが変わっている**

### G1→G2：「指示待ち」から「自分で設計する人」への変化
- 任された業務を、目的を理解したうえでやり切れている
- わからないことを放置せず、自ら質問・学習し前に進めている
- フィードバックを受け、行動が実際に変わっている
- 業務の中で違和感や改善点に気づき、小さくても試している
- 周囲から「この人に任せると安心」「仕事の質が安定している」と見られている

### G2→G3：「自分の仕事」から「チームの成果」に責任が広がる
- 自分の仕事を自分で設計し、安定して成果を出している
- 課題を作業で終わらせず、意味づけして改善につなげている
- 後輩や周囲に対して、判断のしかた・考え方を共有している
- チームの成果や停滞に対して、当事者意識を持って関わっている
- THINK WILD（当たり前を疑う姿勢）が、行動に現れている

### G3→G4：「チーム」から「部門」に責任の射程が広がる
- 短期成果だけでなく、1〜3年先を見据えた判断ができている
- 成果・失敗のどちらに対しても、言い訳せず引き受けている
- 部門やプロジェクト全体を俯瞰し、構造的に考えている
- kiCkらしい判断基準を、自分の言葉と行動で示している
- 周囲から「すでに部門レベルの視点で動いている」と見られている

### G4→G5：「部門」から「会社・未来」への責任の移行
- 部門最適ではなく、全社・社会視点で判断できている
- 成功しているやり方にも疑いを入れ、変化を企てている
- ワクワクする未来像を、意思決定と行動で示している
- 外部との共謀関係を通じて、kiCkの立ち位置を更新している
- 自分が抜けた後も残る、思想・判断基準・問いを残し始めている
- 「この人がkiCkの未来を決めている」と認識されている

## 職種別ロール定義（スキルセット要約）

### クリエイティブ・プロデューサー（CPR）
| Grade | 職種名 | 定義 |
|-------|--------|------|
| G5 | 管掌取締役 | 会社の方針を体現し、みえない価値を変化へ変換し続ける経営の意思決定責任を引き受ける人 |
| G4 | 統括 | 部門単位でマネジメントができ、非連続な成長を実現しているCPR |
| G3 | チームリーダー | チーム単位でアカウントマネジメントができ、非連続な成長に挑戦しているCPR |
| G2 | チーフCPR | クライアント単位・ブランド単位でアカウントマネジメントができるCPR |
| G1 | CPR | 案件単位でアカウントマネジメントができるCPR |

### クリエイティブ：CD（クリエイティブディレクター）
| Grade | 職種名 | 定義 |
|-------|--------|------|
| G5 | - | 全社・業界視点でクリエイティブの方向を決める |
| G4 | ECD+Manager | 部門の未来を引き受け、変化が"続く形"で成立する状態をつくる人 |
| G3 | CD+Manager | 総合的な設計責任を引き受け、チームの未来と質をマネジメントする人 |
| G2 | チーフコピーライター | 言葉によって企画や議論を、より前に・大胆に動かす人 |
| G1 | コピーライター | 言葉によって企画や提案を成立させ、判断の土俵に乗せる人 |

## 評価の4軸（全職種共通）
1. **プロジェクト推進・実行力** — 課題を設定し、成果まで完結させる力
2. **課題発見・設定力** — 本質的な問いを立て、前提を問い直す力
3. **協働・関係構築力** — 内外をつなぎ、推進力を生む力
4. **変革創造力 / 人材育成・組織マネジメント力** — 次を生む力・人を動かす力
